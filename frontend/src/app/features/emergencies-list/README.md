# `emergencies-list/` — llamadas entrantes

## Para qué sirve

Panel izquierdo. Una fila por llamada, la más reciente arriba.

Son **filas compactas, no tarjetas**: en una sala de control importa ver muchas
a la vez y detectar la que está mal.

## Qué muestra cada fila

- Un **punto del color de la prioridad** que calculó el protocolo.
- Código de llamada y hora local.
- La dirección del incidente.
- Las primeras líneas del **texto de la llamada**, tal como se transcribió.
- Un símbolo **⚕** cuando el hospital más cercano no fue el elegido — el caso
  donde Jev cambió el resultado.

Las críticas se pintan con fondo rojizo. Al hacer clic se selecciona: el mapa
ajusta la vista y los paneles derechos muestran su evaluación y su despacho.
