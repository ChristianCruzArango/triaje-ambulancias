3 · El JSON que se envía

Texto de la llamada: «{{ reportText() }}» 

{{ requestBody() }}

Qué es cada campo:

model
Qué modelo responde. jev-latest es un alias que apunta siempre a la última versión estable — hoy jev-1.13.0.
state
Los datos que se juzgan. Todas las preguntas se evalúan contra este mismo estado. Cuanto menos ruido tenga, más acierta.
reportText
El texto de la llamada, tal cual. Es un dato, no una instrucción: va dentro del objeto, nunca pegado a las preguntas.
source
De dónde llegó: voz transcrita, formulario o remisión.
questions
Las preguntas. La clave de cada una (stroke_signs, severe_bleeding…) la elige quien programa, y la respuesta vuelve bajo esa misma clave. Se evalúan todas en paralelo: nueve cuestan lo mismo que una.
type
Qué clase de respuesta se quiere. Aquí se usan dos:
choice — elige una opción de una lista y devuelve la probabilidad de cada una más una confianza.
noul — responde qué tan cierta es una afirmación, con un número de 0 a 1. No trae confianza propia.
(Existe un tercero, score, para puntuar sobre una escala. Este proyecto no lo usa.)
instructions
La pregunta en sí. jev-1.13 responde literalmente lo que dice aquí, no lo que se quiso decir.
criteria
Qué significa cada respuesta posible. En un choice, una descripción por opción. En un noul, qué cuenta como true y qué como false — y tienen que estar alineados con la pregunta: un noul cuyo true signifique «no» rinde peor.

Fuera de esto no viaja nada más. Sin nombre del paciente, sin dirección, sin hora, sin historial.

4 · El JSON que responde

{{ responseBody() }}

Cada respuesta lleva el valor en una clave con el nombre de su tipo: choice trae choice + probabilities + confidence; noul trae solo noul, sin confianza propia.

5 · De dónde sale la confianza

La confianza no es una opinión del modelo: es una estadística calculada sobre la distribución de probabilidades que él mismo devolvió.

Si la probabilidad se concentra en una opción, la confianza es alta. Si se reparte entre varias, es baja — y eso significa que ninguna opción gana con claridad. TypeSafe la calcula y la devuelve ya hecha, pero entrega también las probabilidades completas por si se quiere usar otra medida.

En este proyecto, por debajo de 0,55 el caso NO se despacha solo: va a revisión humana. Los umbrales están en backend/src/jev/constants/triage-thresholds.constant.ts y deben calibrarse con casos reales etiquetados por personal clínico.
